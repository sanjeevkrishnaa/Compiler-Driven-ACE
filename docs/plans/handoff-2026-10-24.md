## Pitfalls learned
* Never edit a tracked ACE source while a baseline check or a long run is going: child runs import the working tree.
* Use `python -B -m unittest discover -s <dir> -p '<pattern>'`; `-t .` fails and `test.test_x` resolves to Python's own `test`.
* zsh: a word starting with `==` and unquoted `--include=*.py` break commands; macOS `sed -i` needs `-i ''`; `xargs -I` has a 255-byte command limit.
* Always compare `average_eligible_latency_ms`, never `average_request_latency_ms`, across schedulers.
* A detached background job needs `start_new_session=True`; a wait loop that greps for its own command line never exits.
