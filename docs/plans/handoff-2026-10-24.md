## Pitfalls learned
* Never edit a tracked ACE source while a baseline check or a long run is going: child runs import the working tree.
* `-t .` fails and `test.test_x` resolves to Python's own `test`; use `python -B -m unittest discover -s <dir> -p '<pattern>'`.
* zsh: `==` at the start of a word and unquoted `--include=*.py` globs break commands; macOS `sed -i` needs `-i ''`.
* The legacy manager's per-request latency leaves out waiting for earlier batches; always compare
  `average_eligible_latency_ms`, not `average_request_latency_ms`, across schedulers.
