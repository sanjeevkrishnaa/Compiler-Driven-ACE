\chapter{Reproducing the results}
\label{app:repro}

All commands are run from the repository root with the project's Python environment. Result folders are dated 2026-10-24.
{\small
\begin{verbatim}
# legacy baseline (must pass after any change to ACE)
python tools/ace_correctness/baseline.py check \
    --golden results/ace_correctness_baseline_2026-10-24/legacy --strict

# tests
python -B -m unittest discover -s test -p 'test_*.py'

# heatmap, Experiment 2
python tools/heatmap/regenerate_heatmap.py --output out/heatmap
python tools/experiment2/make_report.py

# Experiment 1 (mesh), then its analysis
python tools/experiment1/run_experiment1.py --output out --jobs 4
python tools/experiment1/analyze.py --results out/results.csv --output out

# offline routing
python tools/routing_research/run_routing_study.py --output out/routing
python tools/routing_research/simulate_rerouted.py --output out/reroute

# torus: map, then run the experiments
python tools/congestion_study/run_study.py --mapper-dir mapper \
    --topology torus --mapping-only --seeds 42 43 44 --workloads <ten names>
sh tools/torus/run_torus_experiments.sh WORKDIR

# memory cut-off
python tools/cutoff_study/mechanism.py --output out/mechanism.csv

# this report
python tools/latex/make_tables.py
python tools/latex/make_full_tables.py
python tools/latex/make_big_figures.py
tectonic docs/latex/ace_report/main.tex
\end{verbatim}}
Every experiment folder contains \code{run_parameters.json} (all parameters, trace hashes, code commit, machine) and, where timed, \code{timings.csv}.
